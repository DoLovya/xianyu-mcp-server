### 0.1 页面与动作

- 页面 URL：
  - 搜索页：`https://www.goofish.com/search?q=<keyword>`
- 操作步骤（样例）：
  - 输入关键词 `iPhone 13 Pro` 并进入搜索结果页
  - 切换排序到“最新”（页面内部选项，非顶部“新发布”文字本身）
  - 点击分页下一页（确认 pageNumber 变化）

### 0.2 网络请求证据

#### A. 搜索结果（核心）

- method：POST
- url：
  - `https://h5api.m.goofish.com/h5/mtop.taobao.idlemtopsearch.pc.search/1.0/`
- query（脱敏，仅保留结构与常量）：
  - `jsv=2.7.2`
  - `appKey=34839810`
  - `t=<timestamp_ms>`
  - `sign=<masked>`
  - `v=1.0`
  - `type=originaljson`
  - `accountSite=xianyu`
  - `dataType=json`
  - `timeout=20000`
  - `api=mtop.taobao.idlemtopsearch.pc.search`
  - `sessionOption=AutoLoginOnly`
  - `spm_cnt=<masked>`
  - `spm_pre=<masked>`
  - `log_id=<masked>`
- body（脱敏，`application/x-www-form-urlencoded`）：
  - `data=<json-string>`，其 JSON 结构样例如下（字段并非穷举，已按抓包可见字段归纳）：

```json
{
  "keyword": "<keyword>",
  "pageNumber": 1,
  "rowsPerPage": 20,
  "sortField": "",
  "sortValue": "",
  "propValueStr": {},
  "extraFilterValue": "{}",
  "fromFilter": false,
  "searchReqFromPage": "pcSearch",
  "userPositionJson": "{...}",
  "gps": "{...}"
}
```

- 响应摘要（脱敏，仅保留 keys 与结构）：
  - 顶层 keys：`api`, `data`, `ret`, `traceId`, `v`, `responseHeaders`, `retType`
  - `data` keys：`appBar`, `filterBar`, `needDecryptKeys`, `resultInfo`, `resultList`, `resultPrefixBar`, `tabList`, `topList`
  - `data.resultInfo` 常见字段（示例）：`hasNextPage`, `minPrice`, `maxPrice`, `scrollParams`, `trackParams`, `useWaterFall`
  - `data.resultList[*]` 结构：`{ type, style, data }`
  - 单个商品展示字段（从 `data.resultList[0].data.item.main.exContent` 观测到的子集）：
    - `itemId`, `title`, `area`, `picUrl`, `userNickName`, `want`
    - `price` 为“片段数组”（带 `type/text`），不是单一 number
